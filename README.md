# RREV React Website

A polished static React/Vite website concept for Renewable Rise Energy Venture (RREV), based on the supplied 5-page project capability document.

## Run

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Production build

```bash
npm run build
npm run preview
```

## What is included

- Responsive desktop/tablet/mobile design
- Sticky navigation + mobile hamburger
- Animated reveal-on-scroll sections
- Interactive project execution stages
- CBG value-chain visual
- Capability cards
- Leadership section using only the two leaders and experience figures stated in the supplied PDF
- CTA/footer
- No backend or database required

## Important content note

The website intentionally does not invent an address, phone number, email, project location, client list, certifications, awards, plant photographs, or performance figures that were not supplied in the source document. Those can be added once the client provides them.
